# Faceless Studio

Private AI-assisted content production dashboard for long-form YouTube videos and Shorts.

## V0.1 Prototype
- Mobile-first dashboard
- Autopilot toggle
- Create Video flow
- Long video + 3 Shorts simulation
- Pipeline status
- Review / approve / schedule simulation
- No paid server or AI API required yet

## Run locally
Open `index.html` in a browser.
